Live coding 1 — Architecture en couches

Démo en direct

Créer une API Spring Boot simple avec contrôleur, service, repository, DTO et validation.

  1. Générer le projet Spring Boot.
  2. Créer CreateBookRequest, BookController, BookApplicationService.
  3. Expliquer le rôle de chaque couche au fur et à mesure.

Ce que l’enseignant doit dire : “Le contrôleur ne décide pas, il expose. Le service orchestre. Le repository persiste.”

Live coding 2 — Passage monolithe vers services séparés

  1. Copier le module catalogue dans un projet séparé.
  2. Créer une API interne de disponibilité.
  3. Ajouter un client Feign dans le service de prêts.

Erreurs possibles

URL en dur, contrat non documenté, duplication de logique métier, confusion entre API publique et interne.

Live coding 3 — Appel REST et gestion d’erreurs distribuées

  1. Débrancher temporairement catalog-service.
  2. Montrer l’échec côté loan-service.
  3. Ajouter timeout + fallback + message d’erreur maîtrisé.

Live coding 4 — Résilience simple

Configurer Resilience4j et visualiser l’effet du circuit breaker sur plusieurs échecs consécutifs.

Live coding 5 — Logs et traçabilité

Ajouter un filtre de corrélation, propager X-Correlation-Id et montrer les logs corrélés entre gateway et service.

Live coding 6 — Sécurité simple

Protéger un endpoint d’écriture avec JWT et rôle LIBRARIAN. Montrer une requête refusée puis autorisée.
