Architecture Logicielle & Systèmes Distribués

6 jours Master 2

Formation complète de l'architecture monolithique propre jusqu'aux systèmes distribués résilients, avec fil rouge progressif Java / Spring Boot.

🎯 Objectifs globaux

  • Maîtriser les fondamentaux et patterns d'architecture logicielle
  • Concevoir et structurer des applications selon les bonnes pratiques
  • Comprendre les enjeux des systèmes distribués (CAP, cohérence, pannes)
  • Découper un monolithe en microservices et gérer la communication inter-services
  • Implémenter résilience, observabilité et sécurité
  • Documenter, gouverner et déployer une architecture en contexte cloud

Prérequis pour cette formation

  • Java (niveau intermédiaire), bases Spring Boot
  • Compréhension de HTTP, REST, bases de données relationnelles
  • Familiarité avec Git, Maven/Gradle, IDE (IntelliJ recommandé)
  • Docker installé (pour Jours 4-6 et TP2-3)
